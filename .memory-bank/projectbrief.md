# Project brief

## Purpose

Workshop notes for a two half-day workshop on PowerShell and GitHub Copilot,
held in November 2026, prepared as a handout for the participants.

## Scope

- In scope: the README with a recap of every workshop topic, verified
  references, diagrams, a banner, and a screenshot of the demo pipeline.
- Out of scope: the demo project FileManagementSample, which lives in its own
  repository.

## Stakeholders

- Workshop participants, who read the handout.
- The trainer, who maintains the notes.

## Acceptance criteria

1. Every topic from the workshop notes is covered in a form ready to hand to
   the participants.
2. The handout contains no personal names and no company references.
3. Every external link resolves, and every claim is backed by a source or a
   recorded test.
4. The Markdown passes markdownlint with the repository configuration.
